启动与运行

开机自动启动

开机后自动在右下角托盘运行（不弹窗口），局域网 API 随时可用。

关掉这个窗口后，程序会留在右下角托盘里继续运行：左键点托盘图标重新打开窗口，右键托盘图标可以开关开机启动、退出程序。

退出后打印和局域网 API 都会停止，再用桌面图标打开即可。

打印机连接

连接方式 USB 打印队列… 蓝牙串口 打印机和电脑配对后，系统会生成蓝牙串口（「蓝牙链接上的标准串行」）。一般有两个，选编号小的那个；不确定就逐个「保存并检测」，显示可以连接的就是对的。

数据与版本

版本… 程序位置… 数据文件夹… 模板、API 密钥、校准偏移等都在数据文件夹里；卸载程序不会删除。换电脑时把这个文件夹复制过去即可。

密钥管理

局域网设备和其他程序调用 API 都要带密钥。密钥只在生成时完整显示一次，系统里只保存它的指纹；丢了就撤销后重新生成。建议每个调用方（比如"仓库扫码枪""ERP 系统"）各用一个，方便单独撤销和查看调用记录。

接口文档

标签打印服务提供一组 HTTP + JSON 接口：查状态、查模板、按模板打印、直接打印文字、生成预览图。本程序界面用的也是这套接口。

快速开始

  1. 在「服务设置」打开允许局域网访问（只在本机调用可以不开）。
  2. 在「密钥管理」生成一个密钥，复制保存。
  3. 在「标签设计」做好模板（比如「生产日期标签」），需要每次填写的内容写成变量，如 {品名}。
  4. 调用 POST /api/print，传模板名、变量值和份数：
curl -X POST /api/print \
  -H "Authorization: Bearer hm_你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"template": "生产日期标签", "fields": {"品名": "不锈钢螺丝"}, "copies": 2}'

返回 {"ok": true, "printed": 2, "channel": "usb", "serial_next": 27} 就表示已经发给打印机了。

鉴权

除 GET /api/ping 外，所有接口都要在请求头里带密钥，两种写法任选：

Authorization: Bearer hm_你的密钥
X-API-Key: hm_你的密钥
  • 局域网访问关闭时，其他电脑连不上服务（只监听 127.0.0.1）；本机脚本带密钥仍可调用。
  • 模板的新建/修改/删除、密钥管理、服务设置只能在本机的程序界面里操作；API 调用方只能读模板、预览和打印。
  • 浏览器网页可以跨域调用（已开启 CORS），同样必须带密钥。

请求与响应

  • 基础地址：（局域网地址见「服务设置」）
  • 请求体是 UTF-8 编码的 JSON，请求头 Content-Type: application/json。
  • 成功：HTTP 200，{"ok": true, ...}；失败：对应的错误码，{"ok": false, "error": "中文原因"}。
  • 模板可以用 id 或名称指定，如 "prod" 或 "生产日期标签"。
  • 打印机没连上时打印接口直接返回 503，不会排队，调用方可以据此提示用户。

接口列表

POST/api/print按模板打印（最常用）
参数类型说明
template字符串，必填模板 id 或名称
fields对象变量值，如 {"品名": "不锈钢螺丝"}；没传的用模板里保存的默认值，缺了返回 400
copies整数份数，默认 1，一次最多 500
rows数组批量：[{"fields": {...}, "copies": 1}, ...]，传了就忽略 fields / copies
channel字符串auto（=USB）/ driver（USB 经驱动）/ bt（蓝牙），默认用「服务设置」里的

带 {流水号} 的模板每张单独编号，打印成功后服务端自动累加，下次接着打。

// 请求
{"template": "生产日期标签", "fields": {"品名": "不锈钢螺丝"}, "copies": 2}

// 批量请求
{"template": "商品价签", "rows": [
  {"fields": {"品名": "螺丝 M6×20", "价格": "0.35"}, "copies": 10},
  {"fields": {"品名": "垫片 Φ6", "价格": "0.05"}, "copies": 20}
]}

// 成功
{"ok": true, "printed": 2, "channel": "usb", "serial_next": 27}

// 打印机没连上 (HTTP 503)
{"ok": false, "error": "打印机未连接: USB 上没检测到打印机 (没插线、没开机或已自动关机)"}
POST/api/print/text不用模板，直接打几行文字
参数类型说明
lines字符串数组，必填每个元素一行，自动排版；也可以写变量，如 "生产 {日期}"
size[宽, 高]单位 mm，默认 [25, 15]
qr字符串二维码内容，有就放在左边
copies / channel同上
 
{"lines": ["临时标签", "{日期} {时间}"], "size": [25, 15], "copies": 1}
POST/api/preview生成预览图（不打印）

参数同 /api/print 的 template / fields，另有 scale（放大倍数 1~8，默认 1）。返回 image/png，和实际打印的位图一模一样（203 dpi，25×15mm 是 200×120 像素）。也可以用 GET，变量写在网址里：

/api/preview?template=生产日期标签&scale=3&品名=不锈钢螺丝
GET/api/status打印机和服务状态

 "printer": {"model": "HPRT HM-T260L", "online": true, "can_print": true, "via": "usb",
             "bt_port": "COM5", "checked_at": "2026-10-13T23:30:02"},
 "server": {"version": "1.0.0", "port": 8765, "lan": true, "listen": "0.0.0.0",

GET/api/templates模板列表（含每个模板要填的变量） 
{"ok": true, "templates": [
  {"id": "prod", "name": "生产日期标签", "size": [25, 15],
   "elements": [
     {"id": "e1", "type": "text", "x": 1, "y": 1.2, "w": 23, "text": "{品名}", "pt": 11, "bold": true, "align": "center", "shrink": true},
     {"id": "e2", "type": "text", "x": 1, "y": 6.3, "w": 23, "text": "生产 {日期}", "pt": 9, "bold": false, "align": "center", "shrink": true},
     {"id": "e3", "type": "rect", "x": 1, "y": 10.5, "w": 23, "h": 0.3}
   ],
   "fields": {"品名": "不锈钢螺丝"}, "serial": 25, "serial_step": 1,
   "variables": [{"name": "品名", "auto": false}, {"name": "日期", "auto": true, "raw": "{日期}"}]}
]}

variables 里 auto: false 的就是调用 /api/print 时要在 fields 里传的。元素坐标单位 mm；元素类型：text 文本（pt 是字号）/ qr 二维码 / rect 实心线条 / box 方框（t 是线宽）。单个模板：GET /api/templates/{id或名称}。

GET/api/presets标签尺寸预设 
{"ok": true, "sizes": [[25, 15], [30, 20], [40, 30], [50, 30]]}
GET/api/ping服务是否在线（不需要密钥）公开 
{"ok": true, "app": "hanyin-label", "version": "1.0.0"}

错误码

HTTP含义常见原因
400参数错误JSON 格式不对、缺少变量、份数超范围、二维码内容太长
401未授权没带密钥、密钥写错或已被撤销
403禁止局域网访问没开；调用了只允许本机界面使用的接口
404找不到模板名称/id 不存在、接口路径写错
413请求太大请求体超过 2 MB
503打印机未连接USB 没插 / 打印机没开机或已自动关机 / 蓝牙连不上
500服务内部错误详见 data/server.log

代码示例

import requests

BASE = ""
HEADERS = {"Authorization": "Bearer hm_你的密钥"}

# 先看打印机能不能打
st = requests.get(f"{BASE}/api/status", headers=HEADERS, timeout=5).json()
if not st["printer"]["can_print"]:
    raise SystemExit("打印机未连接")

# 按模板打印 2 张
r = requests.post(f"{BASE}/api/print", headers=HEADERS, timeout=30, json={
    "template": "生产日期标签",
    "fields": {"品名": "不锈钢螺丝"},
    "copies": 2,
})
print(r.status_code, r.json())
const BASE = "";
const headers = { "Authorization": "Bearer hm_你的密钥", "Content-Type": "application/json" };

const res = await fetch(`${BASE}/api/print`, {
  method: "POST",
  headers,
  body: JSON.stringify({ template: "生产日期标签", fields: { "品名": "不锈钢螺丝" }, copies: 2 }),
});
const data = await res.json();
if (!data.ok) throw new Error(data.error);   // 503 = 打印机未连接
console.log(`已打印 ${data.printed} 张`);
$base = ""
$headers = @{ Authorization = "Bearer hm_你的密钥" }
$body = @{ template = "生产日期标签"; fields = @{ "品名" = "不锈钢螺丝" }; copies = 2 } | ConvertTo-Json

# 中文要按 UTF-8 发送
Invoke-RestMethod -Method Post -Uri "$base/api/print" -Headers $headers `
  -ContentType "application/json; charset=utf-8" -Body ([Text.Encoding]::UTF8.GetBytes($body))
# Linux / macOS / Git Bash
curl -X POST /api/print \
  -H "Authorization: Bearer hm_你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"template": "生产日期标签", "fields": {"品名": "不锈钢螺丝"}, "copies": 2}'

# 查状态
curl /api/status -H "Authorization: Bearer hm_你的密钥"
