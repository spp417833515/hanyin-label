汉印标签打印 · 5 套界面方案

每套都包含：标签尺寸预设（一键切换）· 标签模板（选尺寸后设计内容，支持 {日期} {流水号} {品名} 这类参数，打印时自动替换）· 快捷编辑 · 打印机在线状态 · 局域网 API 状态。
界面里的按钮都能点：切尺寸、切模板、改文字、点变量插入、填内容，预览会实时变化（打印按钮为演示，不会真的打印）。

方案 E · 迷你窗 + 悬浮条 + 托盘

平时缩成桌面角落的小窗 / 悬浮条，不占地方；后台常驻提供 API。

标签打印
HM-T260L 在线 · USBAPI :8765 运行中
收起后：悬浮条（可拖到屏幕任意位置）
关闭后：托盘右键菜单
全局快捷键 Ctrl+Alt+P：在任何软件里都能按上次内容补打一张（流水号自动 +1）。迷你窗可"置顶"，配合扫码枪边扫边打。
适合电脑主要做别的事，偶尔打标签；或作为后台常驻的 API 服务。
亮点几乎不占屏幕；托盘常驻、开机自启，局域网随时可调用。
代价只能快速打印，复杂设计要打开"完整编辑器"（可用方案 A）。

5 套方案共同的能力

文本参数（变量）写法

模板里写打印时变成（今天实算）

局域网 API（草案）

GET/api/status打印机是否在线、走 USB 还是蓝牙
GET/api/presets尺寸预设列表
GET/api/templates模板列表 + 每个模板需要填的变量
POST/api/print按模板打印：{"template","fields","copies"}
POST/api/print/text不用模板，直接传几行文字 + 尺寸
GET/api/preview返回标签预览 PNG，打印前先看

默认只允许本机；在设置里打开"局域网访问"后需带令牌调用。

其余共同点

  • 尺寸预设一键切换，默认 25×15，可自定义并保存
  • 模板 = 尺寸 + 版式 + 带变量的文字/二维码，存成文件，可复制、导入导出
  • 打印机在线状态每 2 秒刷新（USB），打印前自动唤醒
  • 流水号按模板分别记录，打印成功才递增
  • Excel / CSV 批量：表头对上变量名就自动填
